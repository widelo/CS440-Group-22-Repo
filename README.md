- vacuum_world_master.ipynb

- requirements.txt

1. Put all required files in the same project folder.
2. Install the requirements with: the previous read me file

3. Open the notebook with Jupyter Notebook or VS Code.
4. Open vacuum_world_master.ipynb.
5. Restart the kernel and run all cells from top to bottom.

The notebook calss on the AIMA files and bootstrap.ipynb, so those files must be included so that the actuall notebook can run.
